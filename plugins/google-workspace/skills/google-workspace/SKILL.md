  - gdrive_whoami

# Google Workspace

Start with `gdrive_whoami` to confirm which Google identity the plugin uses and which email files must be shared with.

The remaining Drive, Docs, and Sheets tools are being ported to this Effect-based plugin; see the repository README for status.
